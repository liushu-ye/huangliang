# tools

图标生成脚本，`res/` 下的图标都是从这里出来的。

| 脚本 | 作用 |
| --- | --- |
| `make_icons.py` | 从源图生成自适应图标前景/单色层 + mdpi~xxxhdpi 的传统方形/圆形图标 |
| `make_icon_preview.py` | 把生成结果套上几种常见启动器遮罩渲染成预览图，用来肉眼确认 |

## 重新生成

改一下 `make_icons.py` 顶部的 `SRC`（源图路径），然后：

```bash
python tools/make_icons.py
python tools/make_icon_preview.py
```

源图要求：正方形、浅底深色图案。脚本会用亮度通道把浅底抠成透明。

## 为什么要算安全区

自适应图标画布 108dp，但系统保证可见的只有居中的 72dp；
按圆形遮罩算，半径 36dp。一条半宽 w 的竖排文字能容纳的最大半高是
`sqrt(36² - w²)`。

源图墨迹框 468×1322（宽高比 0.354），代进去解出**墨迹高度上限 66dp**。
取 66dp 时四角距中心 35.7dp，刚好落在安全圆内 —— 所以脚本里
`ADAPTIVE_INK_DP = 66.0` 不是我随手填的。
